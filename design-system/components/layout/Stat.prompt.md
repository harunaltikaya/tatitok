Stat — a quiet label over a large tabular number; the product's primary way of stating a figure.

```jsx
<Stat label="value extracted" value="$4,182.55" sub="4.5× your $920/mo" positive size="hero" />
<Stat label="actual cost" value="$908.49" unpriced unpricedTitle="3 events carry no resolvable price" />
```

Use `positive` + `size="hero"` for the value-extracted number. Pre-format values with the canonical number format (1.18B, $908.49, 4.5×).
