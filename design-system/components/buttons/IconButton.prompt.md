IconButton — square, quiet control for panel chrome (resize −/+, fullscreen ⤢, close ✕) and toolbar glyphs.

```jsx
<IconButton size="sm" label="narrower">−</IconButton>
<IconButton size="sm" label="wider">+</IconButton>
<IconButton label="fullscreen">⤢</IconButton>
```

Pass a Unicode glyph or an SVG node as children. `active` applies the brand-green wash.
