Button — the system's text button (sentence case labels) for range presets, reset, and toolbar actions.

```jsx
<Button variant="default" size="sm">30d</Button>
<Button variant="default" size="sm" active>7d</Button>
<Button variant="subtle" size="sm">clear all</Button>
<Button variant="primary">Add collector</Button>
```

Variants: `default` (hairline surface), `subtle` (ghost), `primary` (brand-green fill — one per view). Sizes: `sm` (28px), `md` (34px). `active` renders the low-key brand-green selected state used by the date-range presets.
